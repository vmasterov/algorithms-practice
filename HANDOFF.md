# HANDOFF — тренировка алгоритмических задач (JS/TS)

## Цель

Подготовка к алгоритмической части собеседования: вспомнить и изучить популярные алгоритмы,
выработать подход к решению и укладываться в 30–40 минут на задачу.
База: книга «Грокаем алгоритмы» + классические задачи в стиле LeetCode.

## Репозиторий

- Локальный путь: `~/…/01 - Обучение/00 - projects/algorithms-practice`
- Язык решений: TypeScript
- Запуск: `npx tsx problems/NNN-slug/solution.ts` (tsx в devDependencies, алиас `@/*` из tsconfig)
- Хелпер тестов: `helpers/test.ts` (`test({ checkFunction, data: [{input, output}], normalization? })`)

### Структура

```
HANDOFF.md
problems/
  NNN-slug/
    README.md     — условие, примеры, ограничения (пишет Claude)
    solution.ts   — решение (пишет пользователь); Claude создаёт заготовку
                    с блоком-памяткой шагов сессии в начале файла
    notes.md      — итоговый разбор (пишет Claude после решения)
```

## Формат работы

1. Claude кладёт условие задачи в репо (`problems/NNN-slug/README.md`), в чат условие не дублирует.
2. Пользователь решает и пишет шаги рассуждения в чат.
3. Claude не пишет код — только подсказывает направление. Код — только по прямой просьбе, затем разбор.
4. После решения Claude пишет `notes.md`: паттерн, сложность, угловые случаи, где застрял, оценка.

### Шаблон сессии (как на собесе)

1. Уточняющие вопросы по условию
2. Примеры и угловые случаи (быстрый перебор входов в голове, без тест-фреймворков)
3. Brute force
4. Оптимизация
5. Оценка сложности (время / память)
6. Код
7. Прогон угловых случаев по коду

### Критерии оценки

Анализ условия · угловые случаи · корректность кода · оценка сложности · уложился во время

## Принятые решения

- Темы идут по паттернам, а не по главам книги: хеш-таблицы, два указателя, скользящее окно,
  бинарный поиск, стек, рекурсия, BFS/DFS, сортировки.
- Первые сессии — простые задачи (Easy), фокус на выработке подхода.
- Тесты = мысленная проверка угловых случаев (на собесе нет времени на vitest).
- Повторение: через 1–2 недели возвращаться к старым задачам и решать с нуля.
