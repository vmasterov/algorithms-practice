# 001. Two Sum

**Сложность:** Easy

## Условие
Дан массив целых чисел `nums` и число `target`. Верни **индексы** двух элементов,
сумма которых равна `target`.

- Гарантируется, что ответ ровно один.
- Один и тот же элемент нельзя использовать дважды.
- Порядок индексов в ответе не важен.

## Примеры

**Пример 1**
```
Вход: nums = [2, 7, 11, 15], target = 9
Выход: [0, 1]
```

**Пример 2**
```
Вход: nums = [3, 2, 4], target = 6
Выход: [1, 2]
```

**Пример 3**
```
Вход: nums = [3, 3], target = 6
Выход: [0, 1]
```

## Ограничения
- `2 <= nums.length <= 10^4`
- Значения могут быть отрицательными

## Сигнатура
```ts
function twoSum(nums: number[], target: number): number[]
```
