# 002. Binary Search

**Сложность:** Easy

## Условие
Дан массив целых чисел `nums`, **отсортированный по возрастанию**, и число `target`.
Верни индекс `target` в массиве. Если такого числа нет — верни `-1`.

Решение должно работать за **O(log n)**.

## Примеры

**Пример 1**
```
Вход: nums = [-1, 0, 3, 5, 9, 12], target = 9
Выход: 4
```

**Пример 2**
```
Вход: nums = [-1, 0, 3, 5, 9, 12], target = 2
Выход: -1
```

**Пример 3**
```
Вход: nums = [5], target = 5
Выход: 0
```

## Ограничения
- `1 <= nums.length <= 10^4`
- `-10^4 < nums[i], target < 10^4`
- Все элементы `nums` уникальны
- `nums` отсортирован по возрастанию

## Сигнатура
```ts
function search(nums: number[], target: number): number
```
