# 004. Valid Palindrome

**Сложность:** Easy

## Условие
Строка — палиндром, если после приведения всех букв к нижнему регистру и удаления
всех символов, кроме букв и цифр, она читается одинаково слева направо и справа налево.

Дана строка `s`. Верни `true`, если она палиндром, иначе `false`.

## Примеры

**Пример 1**
```
Вход: s = "A man, a plan, a canal: Panama"
Выход: true
Пояснение: после очистки — "amanaplanacanalpanama"
```

**Пример 2**
```
Вход: s = "race a car"
Выход: false
Пояснение: после очистки — "raceacar"
```

**Пример 3**
```
Вход: s = " "
Выход: true
Пояснение: после очистки — пустая строка, она читается одинаково в обе стороны
```

## Ограничения
- `1 <= s.length <= 2 * 10^5`
- `s` состоит только из печатных ASCII-символов

## Сигнатура
```ts
function isPalindrome(s: string): boolean
```
