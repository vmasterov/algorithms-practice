# 005. Best Time to Buy and Sell Stock

**Сложность:** Easy

## Условие
Дан массив `prices`, где `prices[i]` — цена акции в день `i`.

Нужно выбрать **один** день для покупки и **другой, более поздний** день для продажи,
чтобы получить максимальную прибыль. Верни максимальную прибыль.
Если заработать нельзя — верни `0`.

## Примеры

**Пример 1**
```
Вход: prices = [7, 1, 5, 3, 6, 4]
Выход: 5
Пояснение: купить в день 1 (цена 1), продать в день 4 (цена 6), прибыль 6 - 1 = 5.
Купить в день 1 и продать в день 0 нельзя — продажа должна быть после покупки.
```

**Пример 2**
```
Вход: prices = [7, 6, 4, 3, 1]
Выход: 0
Пояснение: цены только падают, сделок с прибылью нет.
```

## Ограничения
- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^4`

## Сигнатура
```ts
function maxProfit(prices: number[]): number
```
