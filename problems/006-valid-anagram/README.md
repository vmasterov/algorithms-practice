# 006. Valid Anagram

**Сложность:** Easy

## Условие
Даны две строки `s` и `t`. Верни `true`, если `t` — анаграмма `s`, иначе `false`.

Анаграмма — строка, составленная из тех же букв в том же количестве, но, возможно, в другом порядке.

## Примеры

**Пример 1**
```
Вход: s = "anagram", t = "nagaram"
Выход: true
```

**Пример 2**
```
Вход: s = "rat", t = "car"
Выход: false
```

## Ограничения
- `1 <= s.length, t.length <= 5 * 10^4`
- `s` и `t` состоят только из строчных латинских букв

## Сигнатура
```ts
function isAnagram(s: string, t: string): boolean
```
