# 007. Maximum Average Subarray I

**Сложность:** Easy

## Условие
Дан массив целых чисел `nums` из `n` элементов и число `k`.

Найди **непрерывный** подмассив длины ровно `k` с максимальным средним значением
и верни это среднее. Ответ с погрешностью до `10^-5` считается верным.

## Примеры

**Пример 1**
```
Вход: nums = [1, 12, -5, -6, 50, 3], k = 4
Выход: 12.75
Пояснение: максимальное среднее у подмассива [12, -5, -6, 50]: (12 - 5 - 6 + 50) / 4 = 51 / 4 = 12.75
```

**Пример 2**
```
Вход: nums = [5], k = 1
Выход: 5
```

## Ограничения
- `n == nums.length`
- `1 <= k <= n <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## Сигнатура
```ts
function findMaxAverage(nums: number[], k: number): number
```
