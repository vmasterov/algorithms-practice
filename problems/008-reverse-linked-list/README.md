# 008. Reverse Linked List

**Сложность:** Easy

## Условие
Дана голова `head` односвязного списка. Разверни список и верни новую голову.

Узел списка:
```ts
class ListNode {
  val: number;
  next: ListNode | null;
  constructor(val = 0, next: ListNode | null = null) {
    this.val = val;
    this.next = next;
  }
}
```

## Примеры
Списки записаны массивами для наглядности: `[1, 2, 3]` — это `1 → 2 → 3 → null`.

**Пример 1**
```
Вход: head = [1, 2, 3, 4, 5]
Выход: [5, 4, 3, 2, 1]
```

**Пример 2**
```
Вход: head = [1, 2]
Выход: [2, 1]
```

**Пример 3**
```
Вход: head = []
Выход: []
```

## Ограничения
- Количество узлов: от `0` до `5000`
- `-5000 <= Node.val <= 5000`

## Дополнительно
Список можно развернуть итеративно и рекурсивно. Попробуй оба способа.

## Сигнатура
```ts
function reverseList(head: ListNode | null): ListNode | null
```
