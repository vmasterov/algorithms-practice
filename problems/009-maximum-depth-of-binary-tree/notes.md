# 009. Maximum Depth of Binary Tree — разбор

**Паттерн:** бинарное дерево, рекурсия (DFS) + обход в ширину по уровням (BFS)
**Решения:** рекурсивный DFS, итеративный BFS через очередь — оба верны
**Сложность:**
- DFS (рекурсия) — время O(n), память O(h): O(log n) для сбалансированного дерева, O(n) для вырожденного (стек вызовов)
- BFS (очередь) — время O(n) (с учётом сдвига `shift()` в JS — O(n²), решается указателем `head++`), память O(n) (ширина самого большого уровня — до n/2 узлов)

## Рекурсивный DFS
- База: `root === null` → вернуть `0`.
- Шаг: вычислить глубину левого и правого поддеревьев, вернуть `Math.max(left, right) + 1`.
- Вызовы идут последовательно: память левой ветки очищается из стека до начала обхода правой.

## Итеративный BFS
- Используется очередь (FIFO), а не стек (LIFO).
- На каждой итерации внешнего цикла фиксируем `levelSize = arr.length` и обрабатываем ровно `levelSize` узлов текущего уровня, добавляя их ненулевых детей в конец очереди. После внутреннего цикла делаем `depth++`.

## Проверка
Обе версии сравнены на 5 000 случайных деревьев (до 100 узлов) и на вырожденном дереве из 5 000 узлов — 0 расхождений. Пройдены все 9 ручных кейсов (`null`, 1 узел, баланс, левый/правый бамбуки, отрицательные значения).

## Ошибки по пути
- В первом плане BFS использовался стек (`push` + `pop`) и два счётчика уровней вместо очереди (`shift`) и фиксации `levelSize`.
- В псевдокоде BFS использовался оператор `??` вместо `if (current?.left)`, что привело бы к добавлению `null` в очередь.
- В комментарии сложности сначала перепутаны местами `O(log n)` и `O(n)` для сбалансированного и вырожденного деревьев.

## Мелочи
- В `test` вызов передан только для `maxDepthBFS` — стоит прогонять обе функции.
- `arr.shift()` в JS работает за O(k) из-за сдвига массива; для строгого O(n) лучше двигать индекс `head++`.

## Оценка

| Критерий | Оценка |
|---|---|
| Анализ условия | 5/5 |
| Угловые случаи | 5/5 — пустое, 1 узел, баланс, оба бамбука, отрицательные |
| Код | 5/5 — чистые DFS и BFS |
| Сложность | 5/5 — разобрана глубина стека для баланса и бамбука |
| Время | ~1 ч на вариант (~2 ч суммарно на DFS + BFS; DFS — без подсказок по коду) |

**Подсказок использовано:** 1 (очередь + `levelSize` для BFS)

## На будущее
- В JS при реализации очереди для BFS помнить про стоимость `Array.prototype.shift()` и заменять её на указатель индекса при больших объёмах данных.
- Продолжить закреплять рекурсию на следующих задачах на деревья (Invert Binary Tree / Same Tree).
