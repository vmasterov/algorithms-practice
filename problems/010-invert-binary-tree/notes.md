# 010. Invert Binary Tree — разбор

**Паттерн:** бинарное дерево, рекурсия (post-order DFS) + итеративный обход в ширину (BFS через очередь с указателем)
**Решения:** рекурсивный DFS и итеративный BFS (оба мутируют ссылки на месте) — оба верны
**Сложность:**
- DFS (рекурсия) — время O(n), память O(h): O(log n) для сбалансированного дерева, O(n) для вырожденного (стек вызовов)
- BFS (очередь на массиве с указателем `head`) — время O(n) (честная линейная сложность без сдвига `shift()`), память O(n) (массив хранит все n ссылок до конца обхода)

## Рекурсивный DFS
- База: `if (!root) return null`.
- Шаг: рекурсивно инвертируем `root.left` и `root.right`, затем меняем ссылки местами через `tempLeft` и возвращаем `root`.

## Итеративный BFS
- Используется массив как очередь и индекс чтения `head = 0` вместо дорогого `shift()`.
- Пока `head < arr.length`, берём `item = arr[head]`, меняем местами `item.left` и `item.right`, добавляем ненулевых детей в конец массива и сдвигаем `head++`.

## Проверка
Обе реализации сравнены между собой на 5 000 случайных деревьев и на вырожденном дереве из 5 000 узлов — 0 расхождений. Пройдены все 8 ручных кейсов (`null`, 1 узел, симметрия, асимметрия, полное дерево, бамбук).
